# Phase 9 — Agent Protocols

**Status:** 🚧 Planned — no content yet.

The interoperability layer for agentic systems: how models reach tools & data (MCP), and how independent agents describe, discover & talk to each other (ACP, A2A). Learn MCP first — it's the most established — then the agent-to-agent protocols.

| Track | Scope |
|---|---|
| `MCP/` | Model Context Protocol — servers, clients |
| `ACP/` | Agent Communication Protocol |
| `A2A/` | Agent2Agent Protocol |
