# Model Landscape & Hugging Face

**Status:** ✅ Built.

Hands-on Hugging Face ecosystem: Hub setup, Transformers pipelines/LLMs, Diffusers, video & audio models, Gradio UIs, and loading pretrained models from the Hub. Merged from `Huggingface_Demystified`. Gradio lives here (HF demo surface), not Phase 12.

| Module | Content |
|---|---|
| `00_Setup/` | Hub login, tokens, cache |
| `01_Transformers/` | Datasets, NLP pipelines, tokenization, causal LMs |
| `02_Diffusers/` | Image data, DDPM / Stable Diffusion, AutoPipeline |
| `03_Video_Models/` | Stable Video Diffusion, image-to-video |
| `04_Audio_Models/` | Waveforms, AST classification, ASR/diarization, EnCodec |
| `05_Gradio/` | Interfaces, layout, events, ML integration, theming |
| `06_Pretrained_Models/` | Accessing pretrained models from the Hub |

This is the HF *ecosystem* track. Transformer *architecture* theory stays in `Transformer_Architecture/` (still planned). Fine-tuning lives in `Fine_Tuning_and_RL/`.
