# 04 — AI Coding Tools

**Status:** 🚧 Planned — 2 notebooks, actively being built out.

Agentic coding harnesses and the wider AI coding-tool landscape. Composes what's built in earlier groups into a daily engineering workflow.

**Prerequisites: none, really** — though the material assumes you've written code with an LLM before. This is a top-level group rather than a phase in the learning arc because it covers tools you *use* to build, not a topic you compose into systems.

**`Agent_Skills/`**
- Building Agent Skills
- Using Agent Skills

**`Claude_API_and_Agent_SDK/`**
- Claude API
- Agent SDK
- Tool-use loops

**`AI_Coding_Tool_Landscape/`**
- The wider landscape of AI coding tools
- What agentic, terminal-native tools share mechanically
- Building a toy CLI coding agent from scratch, so the loop stops being an abstraction
