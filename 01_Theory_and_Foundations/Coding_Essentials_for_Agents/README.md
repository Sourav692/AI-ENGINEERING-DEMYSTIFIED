# Coding Essentials for Agents

**Status:** ✅ Built.

Python programming skills used when building AI agents and LLM apps — not agent frameworks themselves (those are Phase 5 / Phase 10). Merged from [`Coding_Essential_For_Agents`](https://github.com/Sourav692/Coding_Essential_For_Agents). Course-level setup notes: `README_COURSE.md`.

| Module | Content |
|---|---|
| `01_Introduction_to_Python/` | Variables, operators, conditionals, loops, functions, PEP 8 / PEP 257 |
| `02_Files_and_Databases/` | NumPy, Pandas, Matplotlib, SQLite, MySQL, PostgreSQL |
| `03_Working_with_APIs/` | Flask routes, Jinja2 templates, Stock Market API project |
| `04_Working_with_LLMs/` | Calling OpenAI / Gemini / Hugging Face APIs and running local Transformers — not LangChain (Phase 2) and not the Hugging Face Hub course (this phase's `Model_Landscape_and_Hugging_Face/`) |
| `05_Threading_and_Multiprocessing/` | Threads, processes, GIL, locks, queues |
| `06_Asyncio/` | `async`/`await`, background workers, race conditions, deadlocks |
