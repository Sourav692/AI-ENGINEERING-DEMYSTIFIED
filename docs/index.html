Design Patterns

The Agentic Playbook

Nine architectural patterns that power modern AI agent systems, each taught with runnable code.

⚙
ReAct

Reason, Act, Observe. The foundational loop where LLMs think, execute a tool, and refine based on the result.

🔧
Tool Use

Direct tool calling vs ReAct-based orchestration — when to use each and the tradeoffs involved.

📚
RAG

Retrieval as standalone pipeline and composable tool. Query rewriting, relevance grading, enterprise vector search.

📋
Planning

Parallel step execution and map-reduce via the Send API. Agents that plan before they act.

🔮
Reflection

Self-evaluation and iterative improvement. Agents that review and refine until quality thresholds are met.

🧠
Long-Term Memory

Persistent state across sessions with PostgreSQL. Agents that remember between conversations.

👥
Multi-Agent

Supervisor agents orchestrating specialized sub-agents with distinct skills and execution environments.

🛑
Human-in-the-Loop

Approval gates, interrupt-and-resume, state modification, and dynamic breakpoints.

🌐
Subgraphs

Composable, modular graph architectures from reusable, independently testable sub-workflows.
