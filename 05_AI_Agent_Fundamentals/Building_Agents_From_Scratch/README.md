# Building Agents From Scratch

**Status:** ✅ Built.

Implement classic agentic patterns with the OpenAI API and a small `agentic_patterns` Python package — **no LangGraph / LangChain**. Merged from `AI-Agents-Essentials` (`2. Building AI Agents from Scratch`). Distinct from `Workflow_and_Agent_Patterns/`, which teaches the same pattern *names* on LangGraph.

| Item | Content |
|---|---|
| `1. Reflection Pattern.ipynb` … `4. Multiagent Pattern.ipynb` | Colab-style notebooks for reflection, tool use, planning, multi-agent |
| `5. Building a Real Wold AI Agent From Scratch.ipynb` | End-to-end from-scratch agent (filename spelling unchanged) |
| `Agentic Patterns/` | Installable `agentic_patterns` package (`src/`) plus matching notebooks |
| `images/` | Diagrams used by the notebooks |
