RAG Retrieval Strategies

A retriever decides what context the LLM sees — everything downstream is bounded by it. Nine strategies, from naive top-k search to reranked hybrid pipelines, with runnable LangChain code.

01 Basic Similarity Search

What it is: Embed the query, run a nearest-neighbor search against the vector store, return the top-k chunks. The default retriever every vector store exposes.

When to use it: Baseline for any RAG system — measure this before reaching for anything below.

Limitation: The top-k results are often near-duplicates of each other, wasting context budget.

vectorstore = Chroma.from_documents(docs, embedding=embeddings)
retriever = vectorstore.as_retriever(search_kwargs={"k": 4})
results = retriever.invoke("What is LangGraph used for?")

02 Maximal Marginal Relevance (MMR)

What it is: Retrieves a larger candidate pool, then greedily selects results that balance relevance against diversity from what's already selected.

When to use it: Overlapping or redundant corpus content keeps producing near-identical top-k results.

retriever = vectorstore.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 4, "fetch_k": 20, "lambda_mult": 0.5},
)

03 Multi-Query Retrieval

What it is: An LLM rewrites the query into several phrasings, each is searched independently, and the unique union of results is returned.

When to use it: Recall problems from vocabulary mismatch between the user's phrasing and the corpus.

# from langchain.retrievers.multi_query import MultiQueryRetriever
multi_query_retriever = MultiQueryRetriever.from_llm(
    retriever=vectorstore.as_retriever(search_kwargs={"k": 3}),
    llm=llm,
)
docs = multi_query_retriever.invoke("How do I persist embeddings?")
Tradeoff: one extra LLM call to generate variations, plus N searches instead of one.

04 Self-Query Retrieval

What it is: An LLM parses the query into a structured metadata filter plus a semantic search string, using a schema you define over your metadata.

When to use it: Documents carry rich metadata and users mix semantic intent with hard filters ("papers after 2019 about attention").

# from langchain.retrievers.self_query.base import SelfQueryRetriever
metadata_field_info = [
    AttributeInfo(name="topic", description="'rag', 'agents', or 'langgraph'", type="string"),
    AttributeInfo(name="year", description="publication year", type="integer"),
]
self_query_retriever = SelfQueryRetriever.from_llm(
    llm=llm, vectorstore=vectorstore,
    document_contents="Technical notes on LLM frameworks",
    metadata_field_info=metadata_field_info,
)

05 Contextual Compression

What it is: Wraps a base retriever; after retrieval, an LLM strips each chunk down to only the sentences relevant to the query.

When to use it: Chunks are long and only a fraction is actually relevant — compression reduces prompt size and noise.

# from langchain.retrievers import ContextualCompressionRetriever
# from langchain.retrievers.document_compressors import LLMChainExtractor
compressor = LLMChainExtractor.from_llm(llm)
compression_retriever = ContextualCompressionRetriever(
    base_compressor=compressor,
    base_retriever=vectorstore.as_retriever(search_kwargs={"k": 4}),
)
Tradeoff: one LLM call per retrieved document — the most expensive strategy here per query.

06 Hybrid Search (BM25 + Semantic)

What it is: Combines a sparse keyword retriever (BM25) with dense semantic search, merging ranked results via EnsembleRetriever.

When to use it: Queries mix natural language with exact-match needs — product codes, error messages, function names.

# from langchain_community.retrievers import BM25Retriever
# from langchain.retrievers import EnsembleRetriever
bm25_retriever = BM25Retriever.from_documents(docs)
bm25_retriever.k = 3
ensemble_retriever = EnsembleRetriever(
    retrievers=[bm25_retriever, vectorstore.as_retriever(search_kwargs={"k": 3})],
    weights=[0.4, 0.6],
)

07 Parent-Document Retriever

What it is: Indexes small child chunks for precise matching, but returns the larger parent chunk they belong to.

When to use it: Small chunks retrieve precisely but lack context; large chunks have the opposite problem.

# from langchain.retrievers import ParentDocumentRetriever
# from langchain.storage import InMemoryStore
parent_doc_retriever = ParentDocumentRetriever(
    vectorstore=vectorstore,
    docstore=InMemoryStore(),
    child_splitter=RecursiveCharacterTextSplitter(chunk_size=200, chunk_overlap=20),
    parent_splitter=RecursiveCharacterTextSplitter(chunk_size=800, chunk_overlap=100),
)

08 HyDE (Hypothetical Document Embeddings)

What it is: An LLM generates a hypothetical answer to the query first; that hypothetical answer is embedded and used for the similarity search instead of the raw query.

When to use it: Short, vague queries that don't share vocabulary with dense technical documents.

hyde_chain = hyde_prompt | llm | StrOutputParser()

def hyde_retrieve(question, k=4):
    hypothetical_doc = hyde_chain.invoke({"question": question})
    return vectorstore.similarity_search(hypothetical_doc, k=k)

09 Reranking (Cross-Encoder)

What it is: A two-stage pipeline — cheap vector search casts a wide net (k=20-50), then a cross-encoder scores each (query, document) pair jointly and reorders by that more accurate score.

When to use it: The right chunk is retrieved but ranked too low at small k — the standard fix in production search.

# from langchain_community.cross_encoders import HuggingFaceCrossEncoder
# from langchain.retrievers.document_compressors import CrossEncoderReranker
cross_encoder = HuggingFaceCrossEncoder(model_name="BAAI/bge-reranker-base")
reranker = CrossEncoderReranker(model=cross_encoder, top_n=3)
reranking_retriever = ContextualCompressionRetriever(
    base_compressor=reranker,
    base_retriever=vectorstore.as_retriever(search_kwargs={"k": 20}),
)

Production Composite Pipeline

Real systems rarely use one strategy alone. A common, battle-tested pipeline:

1Hybrid RetrievalBM25 + semantic, wide candidate pool (k≈10 each)
↓
2Cross-Encoder RerankScore candidates jointly, keep top 5
↓
3Contextual CompressionTrim each chunk to the relevant sentences
↓
4GenerationLLM answers from compressed, reranked context
hybrid = EnsembleRetriever(retrievers=[bm25, semantic], weights=[0.3, 0.7])
reranker = CrossEncoderReranker(model=cross_encoder, top_n=5)
production_retriever = ContextualCompressionRetriever(
    base_compressor=reranker, base_retriever=hybrid,
)
