Each engagement carries the same two formats where they exist — a **15–20 minute
deep-dive** for a scheduled slot, and a **conversational guide** for a fluid discussion.
Pick by the shape of the interview, not the project.

folder is the source — then carry the change across if the worked example still needs to
match.
