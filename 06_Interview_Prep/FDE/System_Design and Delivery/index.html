An agentic AI travel assistant spanning AMER, EMEA, and APJ — reconciling a reference architecture with five structural fixes: rate limiting inside the gateway, a cache-first supervisor, per-agent RAG, tool calls scoped to each agent's own turn, and a Synthesizer Agent that resolves conflicts before the response goes out.
