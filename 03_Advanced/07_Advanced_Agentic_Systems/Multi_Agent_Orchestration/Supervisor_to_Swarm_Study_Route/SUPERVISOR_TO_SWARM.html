Before you start

Four things that will bite you

All four are live in this repo right now, on LangChain 1.4. Recognising them saves an hour each.

ImportError

The legacy agent API moved. create_tool_calling_agent and AgentExecutor are no longer in langchain.agents — that package now exports only create_agent. They live in langchain_classic.agents, the same relocation as langchain.chains.

Deprecated

create_react_agent is on the way out. Deprecated in LangGraph v1.0, removal planned for v2.0. The replacement is create_agent from langchain.agents — and the argument prompt was renamed system_prompt, so renaming only the function raises TypeError.

KeyError

A TypedDict does not create keys. It is an annotation, nothing more. Invoke a graph with {"query": q} and a node reading state["metadata"] raises immediately — annotated-but-unset fields are simply absent. Fields with a reducer get a default; plain ones do not. Use state.get(...).

Duplicates

Never mutate state in a node. With an Annotated[list, operator.add] channel, appending to state["messages"] edits the channel's own list, and returning it makes the reducer add it a second time — every entry appears twice. Return a partial update containing only the new items.
