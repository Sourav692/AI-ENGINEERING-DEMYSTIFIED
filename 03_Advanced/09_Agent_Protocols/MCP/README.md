# MCP (Model Context Protocol)

**Status:** ✅ Built.

A protocol, not a framework — connecting LLMs to tools/data via standardized servers and clients. Merged from `MCP_Demystified`. Each source course was kept whole (shared servers, `uv.lock`, Chroma DBs, images).

| Subfolder | Content |
|---|---|
| `01_Foundations/` | Anthropic *Build Rich-Context AI Apps with MCP* (L3–L9) + Educative MCP Fundamentals (Wikipedia research assistant) |
| `02_Building_Servers/` | Educative *Mastering MCP* (single/multi-server) + Databricks Apps custom MCP server |
| `03_Building_Clients/` | MCP Essential: own server+client, multi-server client, SSE, streamable HTTP |
| `04_Applications/` | Udemy *MCP Mastery* (Claude Desktop, data-analysis servers, RAG + LangChain, LangGraph research assistant, EC2 deploy) |
| `04_Applications/mcp_a2a_agentic_rag/` | Standalone MCP + A2A agentic RAG app — the single canonical copy (no Phase 8 duplicate, despite older notes). Moved under `04_Applications/` on 2026-09-19; it is an application, which is what that folder holds |
