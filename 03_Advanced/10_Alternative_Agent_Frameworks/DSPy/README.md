# DSPy

**Status:** ✅ Built.

Programmatic prompting / context engineering with DSPy. The `context-engineering-dspy/` course is kept **whole** (shared `print_utils`, RAG scripts, `uv.lock`) rather than split into Phase 2 Context Engineering or Phase 4/8 RAG.

Merged from [`DSPy_Demystified`](https://github.com/Sourav692/DSPy_Demystified). Course README: `context-engineering-dspy/README.md`.

| Level | Content |
|---|---|
| `level1_atomic_prompts/` | Atomic DSPy prompts |
| `level2_multi_interaction/` | Sequences, iteration, branching, reflection |
| `level3_evaluation/` | Evaluation / pairwise Elo |
| `level4_tools/` | Tool-calling agent |
| `level5_rags/` | DSPy RAG variants (HyDE, BM25, fusion) — stays here with the course |
