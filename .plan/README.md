# `.plan/`

Migration and refactor plans generated by Claude Code skills, one file per target folder.

Each plan is a **living checklist**, not a one-shot report — rows are `- [ ]` / `- [x]`, so a plan
tracks how far its migration actually got, across sessions. Re-running the generating skill over the
same folder refreshes the counts and unticked rows while preserving ticked ones and any editorial
decisions already recorded, and appends a `## Changelog` entry.

## Naming

```
<target-folder-name>_<topic>_plan.md
```

e.g. `04_Chains_langchain_v1_plan.md`. Folder names that recur across phases (`01_Foundations`,
`LangGraph`) are prefixed with their owning phase so plans never collide.
