# Onboarding Guide

All enterprise assistant users should understand the following principles:

- Answers must be grounded in approved sources.
- If no approved source exists, the assistant should say so.
- Sensitive identifiers should be redacted in generated drafts.
- Users should not paste secrets, credentials, or private keys into the assistant.
- High-risk answers in legal, healthcare, finance, and security workflows require human review.

Example safe response:

"I could not find approved context for that request. Please check the source system or ask an authorized reviewer."
