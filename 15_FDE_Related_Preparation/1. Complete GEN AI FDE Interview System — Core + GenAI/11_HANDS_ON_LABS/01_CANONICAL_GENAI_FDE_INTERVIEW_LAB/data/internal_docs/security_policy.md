# Security Policy

This document is restricted to managers and admins.

Security evidence rules:

- SOC2 reports may be shared only through the approved trust portal.
- Security questionnaires must be reviewed by the security owner before sending.
- Customer-specific architecture diagrams require manager approval.
- Prompt injection findings must be logged as security events.

Restricted security escalation:

- Admin-only incident escalation uses the secret escalation channel.
- Do not expose internal escalation aliases, private dashboards, or control owners to unauthorized roles.
- Any suspected customer data leakage must be treated as a high-severity incident until disproven.
